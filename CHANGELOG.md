# Changelog

All notable changes to this project will be documented here.

## 1.0.0 - 2026-08-20

- Add validated LPS35HW pressure and temperature sampling.
- Add bounded Arduino UNO R4 Minima I2C transactions and bus recovery.
- Add startup surface-pressure calibration retained across runtime recovery.
- Add freshwater and saltwater depth conversion.
- Add an optional motor-off callback for fail-safe control loops.
